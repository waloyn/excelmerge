# ExcelMerge - 现代化 Excel 表格批量合并工具

一款基于 **Go 语言** 编写的现代化表格合并桌面工具。专为批量汇总大量报表数据设计，提供**简洁直观的原生卡片式 UI**，且 **100% 兼容 Windows 7、Windows 10 与 Windows 11**，单文件绿色免安装，开箱即用。

---

## ✨ 核心特性

- **现代简洁原生界面**：采用卡片式分组布局，内置平滑进度条与彩色分级日志；全面支持将 Windows 资源管理器中的**文件夹直接拖拽至窗口**快速载入。
- **纯 Go 驱动，免装 Office**：无需目标电脑安装 Microsoft Excel、WPS Office 或任何第三方运行库，纯代码流式解析与写入。
- **全格式表格支持**：
  - 现代 Excel 工作簿：`.xlsx`、`.xlsm`（基于 `excelize/v2` 高性能读写，保留格式化数值与日期）。
  - 经典旧版表格：`.xls`（Excel 97-2003 BIFF8 格式）。
  - 纯文本数据表：`.csv`（内置智能编码识别，自动兼容 Windows ANSI/GBK 与 UTF-8 中文编码）。
- **极佳的系统兼容性（兼容 Win7）**：
  - 基于官方正式支持 Windows 7 的 **Go 1.20** 编译器构建。
  - 基于纯 Win32 API 与 Common-Controls 6.0 现代视觉样式，无 WebView2、DirectX 或 OpenGL 等外部驱动依赖。
  - 干净的桌面体验：彻底去除命令行黑框，双击直接启动 GUI，单文件体积仅约 **10 MB**，运行内存占用仅约 **15~25 MB**。
- **强健的合并与排错规则**：
  - **多样化输出方式**：支持“单表汇总模式”（全部文件数据合并到单个工作表）与“多表输出模式”（每个待合并文件独立生成一个工作表，同名文件智能防重名冲突）。
  - **表头智能处理**：仅保留首个表格的表头，后续表格自动跳过指定行数（支持 0~1000 行可调）。
  - **工作表（Sheet）选择**：支持“仅首个工作表”、“所有工作表”以及“通配符过滤”（例如 `销售*,汇总`）；多表输出模式下，单文件多 Sheet 依然受该规则约束。
  - **来源追溯列**：可选在生成表格最前面自动新增两列：`来源文件`、`来源工作表`。
  - **异常与边界防护**：列数不一致警告提示、自动排除 Office 临时文件（`~$*`, `.~*`）与输出文件自身、单表最大 1,048,576 行上限熔断保护。

## 🚀 快速上手

### 1. 下载与运行
直接运行工程根目录下的可执行文件：
```text
ExcelMerge.exe
```

### 2. 操作指南
1. **指定源目录**：
   - 点击 **【浏览目录...】** 选择待合并表格所在文件夹；或者**直接从资源管理器拖放文件夹到程序窗口**。
   - 程序将自动推导并在该目录下生成带时间戳的输出文件名（例如：`合并结果_20261111_164500.xlsx`），也可点击 **【更改路径...】** 自定义保存位置。
2. **配置合并选项**：
   - **表头行数**：默认 1 行。若表格有 2 行或多行表头，调整对应数值即可。
   - **输出方式**：
     - *所有数据合并至单表 (默认)*：将全部文件的数据汇集在一张工作表；
     - *每个文件独立工作表 (多表输出)*：每个输入文件生成一个单独的工作表，便于分表归档。
   - **工作表筛选**：默认选择“仅首个工作表”；需要合并多 Sheet 时可切换为“所有工作表”或输入名称匹配规则（如 `销售*`）。多表输出时依然严格生效。
   - **包含子目录文件**：勾选后将自动递归扫描所有层级的子文件夹。
   - **在首部增加[来源文件/工作表]列**：方便追踪汇总后的数据归属哪个文件及 Sheet。
3. **开始处理**：
   - 点击 **【开始合并表格】**，实时进度条将动态推进，运行日志区域将打印每个工作表的详细处理记录与行数。
   - 若发现选错路径，可随时点击 **【终止合并】** 安全取消。

## 🛠️ 构建与二次开发

本项目建议使用支持 Windows 7 的 Go 1.20 工具链进行编译。

### 环境要求
- [Go 1.20](https://golang.google.cn/dl/)（若机器安装了版本管理工具 `g`，可使用 `g use 1.20` 切换）
- [rsrc](https://github.com/akavel/rsrc)（用于打包 Windows Manifest 清单）

### 一键构建
在 Windows 命令行或 PowerShell 下直接执行工程目录自带的打包脚本：
```cmd
build.bat
```

### 手动构建命令
```powershell
# 1. 切换至 Go 1.20
g use 1.20

# 2. 生成包含 Windows 现代控件样式的 PE 资源文件
rsrc -manifest manifest.xml -o rsrc.syso

# 3. 编译发布版二进制（-H windowsgui 消除黑框，-s -w 压缩体积）
go build -ldflags="-H windowsgui -s -w" -o ExcelMerge.exe .
```

### 运行自动化单元测试
```powershell
g use 1.20
go test -v ./internal/merger
```

## ❓ 常见问题 (FAQ)

**Q：为什么可以在纯净的 Windows 7 上直接双击运行？**  
A：Go 官方从 1.21 起弃用了对 Win7 的系统调用支持。本项目严格选用 Go 1.20 工具链，并采用原生 Win32 API 控件，绝不引入 WebView2 或高版本专用 API，在任何脱机或老旧 Win7 SP1 电脑上均可直接运行。

**Q：合并过程中界面会卡死或未响应吗？**  
A：不会。合并任务运行在独立的后台 Goroutine 中，并通过 `walk.Synchronize` 调度更新 UI，处理百万级数据也能保持窗口流畅拖动与响应。

**Q：公式会被如何处理？**  
A：读取器会提取单元格的计算结果值并写入新文件，避免生成后的汇总文件因缺少源文件引用而出现 `#REF!` 错误。
